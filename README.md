# 🤖 ربات مدیریت DNS کلودفلر (Cloudflare DNS Manager Bot)

رباتی ساده و قدرتمند برای مدیریت دامنه‌ها و رکوردهای DNS در حساب Cloudflare شما از طریق تلگرام.

---

## 🚀 نصب یک‌دستوری

در ترمینال لینوکس (Ubuntu/Debian) فقط این دستور را وارد کنید:

```bash
bash <(curl -Ls --ipv4 https://raw.githubusercontent.com/0fariid0/cloudflare_dns_bot/main/setup.sh)
```

> این دستور به صورت خودکار:
> - وابستگی‌ها را نصب می‌کند (Python، pip و پکیج‌های مورد نیاز)
> - سورس ربات را دانلود می‌کند
> - فایل تنظیمات را آماده می‌سازد
> - و ربات را به عنوان سرویس فعال می‌کند

---

## ⚙️ امکانات ربات

- 🌐 نمایش لیست دامنه‌های متصل به Cloudflare
- 📋 نمایش رکوردهای DNS هر دامنه (A, AAAA, CNAME)
- ➕ افزودن رکورد جدید در چند مرحله
- 📝 ویرایش IP/Content و TTL
- 🔄 تغییر وضعیت Proxied رکوردها (On/Off)
- 🗑 حذف رکورد یا دامنه با تایید
- 🔐 سیستم درخواست دسترسی + مدیریت کاربران (برای ادمین)
- 🔙 بازگشت به منوی قبلی در مراحل مختلف (مثلاً بعد از کلون)
- ✅ پشتیبانی از **Cloudflare API Token (پیشنهادی)** و همچنین **Global API Key**

---

## 🔑 ساخت Cloudflare API Token (پیشنهادی)

در Cloudflare به مسیر زیر بروید:

- **My Profile → API Tokens → Create Token**

دسترسی‌های حداقلی که این ربات نیاز دارد:

- `Zone → Zone → Read`
- `Zone → DNS → Edit`

و در بخش **Zone Resources**:

- `Include → All zones` (یا دامنه‌های مشخص)

---

## 📦 فایل تنظیمات (`config.py`)

```python
BOT_TOKEN = "توکن ربات تلگرام"

# Cloudflare:
# - اگر از API Token استفاده می‌کنید (پیشنهادی):
#   مقدار توکن را داخل CLOUDFLARE_API_KEY قرار دهید و CLOUDFLARE_EMAIL می‌تواند خالی باشد.
# - اگر از Global API Key استفاده می‌کنید:
#   CLOUDFLARE_EMAIL و CLOUDFLARE_API_KEY (Global Key) را هر دو وارد کنید.
CLOUDFLARE_EMAIL = ""
CLOUDFLARE_API_KEY = "توکن یا کلید"

# ایدی عددی تلگرام ادمین
ADMIN_ID = 123456789
```

## 🛠️ کنترل سرویس ربات

پس از نصب، ربات به صورت یک سرویس لینوکسی اجرا می‌شود.

| عملیات | دستور |
|--------|--------|
| 🔍 بررسی وضعیت | `sudo systemctl status cloudflarebot` |
| ▶️ استارت ربات | `sudo systemctl start cloudflarebot` |
| 🔄 ریستارت ربات | `sudo systemctl restart cloudflarebot` |
| ⛔️ توقف کامل | `sudo systemctl stop cloudflarebot` |
| 🚫 غیرفعال‌سازی (از بوت) | `sudo systemctl disable cloudflarebot` |
| ✅ فعال‌سازی (خودکار هنگام روشن‌شدن) | `sudo systemctl enable cloudflarebot` |

## 🆕 منوهای منظم و مرکز کلون‌ها

منوی اصلی بخش‌های جداگانهٔ **دامنه‌ها، گروه‌ها، مرکز کلون‌ها، تغییر گروهی، جست‌وجو، مانیتورینگ و تاریخچه** دارد.

- **مرکز کلون‌ها:** کلون‌های ثبت‌شدهٔ همهٔ گروه‌ها و کلون‌های تکی را یکجا، بر اساس گروه یا IP ببینید؛ هر رکورد تنظیمات و حذف با تأیید دارد.
- **کلون تکی:** از تنظیمات رکورد A یا AAAA، «کلون» را بزنید و IPهای مقصد را بفرستید. یک گروه اختصاصی برای منبع ساخته می‌شود و کلون‌ها پس از تأیید در مرکز کلون‌ها ثبت می‌شوند.
- **کلون‌های قدیمی / هم‌نام:** این گزینه در مرکز کلون‌ها، رکوردهای A/AAAA با نام و نوع یکسان را پیدا می‌کند. رکورد هم‌نام الزاماً کلون نیست؛ این اسکن هیچ رکوردی را خودکار ثبت، تغییر یا حذف نمی‌کند.
- **گروه‌ها:** در صفحهٔ خود گروه، IPهای اصلی و کلون‌ها با مقدار فعلی Cloudflare کنار هم نمایش داده می‌شوند. هر ردیف دکمهٔ تغییر IP، حذف با تأیید و مشاهدهٔ رکوردهای همان IP دارد؛ افزودن کلون جدید نیز در همین صفحه است. تغییر نام و ویرایش کلی از «تنظیمات گروه» در دسترس‌اند. در انتخاب اعضا، ➕ یعنی افزودن و ✅ یعنی برداشتن از گروه؛ رکورد DNS حذف نمی‌شود.
- **حذف گروه:** رکورد DNS را حذف نمی‌کند. تا وقتی گروه کلون ثبت‌شده دارد، ابتدا باید تکلیف کلون‌ها مشخص شود. کلونی که عضو اصلی هر گروهی شده باشد، از مسیر حذف کلون پاک نمی‌شود.
- **ویرایش کلون:** ویرایش از داخل همین ربات، فهرست کلون‌ها را به‌روز می‌کند. تغییر بیرونیِ نام، نوع یا IP ممکن است حذف کلون را برای بررسی متوقف کند.
- **لغو:** `/cancel` یا `/start` ورودی و تأیید معلق را پاک می‌کند و به خانه برمی‌گردد.

### به‌روزرسانی نسخهٔ نصب‌شده

1. کل محتویات سورس، از جمله فایل جدید `bot_runtime.py` را در ریشهٔ مخزن GitHub بارگذاری کنید. `config.py` و فایل‌های اطلاعات کاربران/دیتابیس را در GitHub نگذارید.
2. همان دستور **نصب یک‌دستوری بالای README** را اجرا کنید و گزینهٔ **3 — Update from GitHub** را بزنید.
3. تنظیمات و اطلاعات قبلی از پشتیبان برگردانده می‌شوند. از مسیر پشتیبان اعلام‌شده نگهداری کنید.
4. در تلگرام `/start` بفرستید تا منوهای جدید باز شوند.

دریافت سورس پیش از توقف سرویس انجام می‌شود. در نصب مجدد، سورس قبلی تا پایان نصب جدید حفظ می‌شود؛ در خطای نصب/به‌روزرسانی، بازگردانی نسخهٔ قبلی تلاش می‌شود. بازگردانی خودکار در صورت خطای سیستم‌عامل، وابستگی یا شبکه تضمین‌شده نیست؛ خطای نهایی و لاگ سرویس را بررسی کنید.

### آزمون‌های آفلاین

این آزمون‌ها از پاسخ‌های شبیه‌سازی‌شده استفاده می‌کنند و به توکن واقعی نیاز ندارند:

```bash

.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
bash -n setup.sh install.sh
```

آزمون زنده با حساب Cloudflare و ربات تلگرام باید پس از نصب انجام شود. کارهای چندرکوردی در Cloudflare تراکنش یکپارچه نیستند؛ اگر بخشی ناموفق شود، نتیجهٔ موفق و ناموفق جداگانه گزارش می‌شود و تغییرات موفق حفظ می‌شوند.


### مدیریت مستقیم IP اصلی و کلون در صفحهٔ گروه

- ⭐ **اصلی** و 🧬 **کلون** از هم مشخص‌اند. رکوردهای هم‌نوع با IP یکسان در یک ردیف جمع می‌شوند.
- **تغییر IP / مقدار** فقط رکوردهای همان ردیف را تغییر می‌دهد؛ IPهای سایر ردیف‌ها دست‌نخورده می‌مانند.
- **حذف رکوردها** پس از پیش‌نمایش و تأیید، رکوردهای همان ردیف را از خود Cloudflare حذف می‌کند. حذف IP اصلی، کلون‌ها را حذف نمی‌کند و حذف یک IP کلون هم سایر کلون‌ها یا IP اصلی را پاک نمی‌کند.
- برای مدیریت یک رکورد از بین چند رکورد روی یک IP، روی عنوان ردیف بزنید؛ ویرایش یا حذف تکی از آنجا انجام می‌شود.
- حذف رکورد اصلی، عضویت همان رکورد را در گروه‌های دیگر نیز برمی‌دارد. «برداشتن از گروه» بدون حذف DNS همچنان از «اعضای اصلی» قابل انجام است.
- مقدارها از Cloudflare خوانده می‌شوند. تغییر دسترسی، عضویت یا خود رکورد پس از نمایش/پیش‌نمایش، عملیات قدیمی را متوقف می‌کند.
