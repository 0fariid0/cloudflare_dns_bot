# 🤖 ربات مدیریت DNS کلودفلر (Cloudflare DNS Manager Bot)

رباتی ساده و قدرتمند برای مدیریت دامنه‌ها و رکوردهای DNS در حساب Cloudflare شما از طریق تلگرام.

---

## 🚀 نصب یک‌دستوری

در ترمینال لینوکس (Ubuntu/Debian) فقط این دستور را وارد کنید:

```bash
bash <(curl -Ls --ipv4 https://raw.githubusercontent.com/0fariid0/cloudflare_dns_bot/main/setup.sh)
```

> این دستور به صورت خودکار:
> - وابستگی‌ها را نصب می‌کند (Python، pip و پکیج‌های مورد نیاز)
> - سورس ربات را دانلود می‌کند
> - فایل تنظیمات را آماده می‌سازد
> - و ربات را به عنوان سرویس فعال می‌کند

---

## ⚙️ امکانات ربات

- 🌐 نمایش لیست دامنه‌های متصل به Cloudflare
- 📋 نمایش رکوردهای DNS هر دامنه (A, AAAA, CNAME)
- ➕ افزودن رکورد جدید در چند مرحله
- 📝 ویرایش IP/Content و TTL
- 🔄 تغییر وضعیت Proxied رکوردها (On/Off)
- 🗑 حذف رکورد یا دامنه با تایید
- 🔐 سیستم درخواست دسترسی + مدیریت کاربران (برای ادمین)
- 🔙 بازگشت به منوی قبلی در مراحل مختلف (مثلاً بعد از کلون)
- ✅ پشتیبانی از **Cloudflare API Token (پیشنهادی)** و همچنین **Global API Key**

---

## 🔑 ساخت Cloudflare API Token (پیشنهادی)

در Cloudflare به مسیر زیر بروید:

- **My Profile → API Tokens → Create Token**

دسترسی‌های حداقلی که این ربات نیاز دارد:

- `Zone → Zone → Read`
- `Zone → DNS → Edit`

و در بخش **Zone Resources**:

- `Include → All zones` (یا دامنه‌های مشخص)

## 📦 فایل تنظیمات (`config.py`)

```python
BOT_TOKEN = "توکن ربات تلگرام"

# Cloudflare:
# - اگر از API Token استفاده می‌کنید (پیشنهادی):
#   مقدار توکن را داخل CLOUDFLARE_API_KEY قرار دهید و CLOUDFLARE_EMAIL می‌تواند خالی باشد.
# - اگر از Global API Key استفاده می‌کنید:
#   CLOUDFLARE_EMAIL و CLOUDFLARE_API_KEY (Global Key) را هر دو وارد کنید.
CLOUDFLARE_EMAIL = ""
CLOUDFLARE_API_KEY = "توکن یا کلید"

# ایدی عددی تلگرام ادمین
ADMIN_ID = 123456789
```

## 🛠️ کنترل سرویس ربات

پس از نصب، ربات به صورت یک سرویس لینوکسی اجرا می‌شود.

| عملیات | دستور |
|--------|--------|
| 🔍 بررسی وضعیت | `sudo systemctl status cloudflarebot` |
| ▶️ استارت ربات | `sudo systemctl start cloudflarebot` |
| 🔄 ریستارت ربات | `sudo systemctl restart cloudflarebot` |
| ⛔️ توقف کامل | `sudo systemctl stop cloudflarebot` |
| 🚫 غیرفعال‌سازی (از بوت) | `sudo systemctl disable cloudflarebot` |
| ✅ فعال‌سازی (خودکار هنگام روشن‌شدن) | `sudo systemctl enable cloudflarebot` |

## مدیریت جمع‌وجور گروه‌ها

- صفحهٔ هر گروه فقط نام گروه و ردیف IPها را نشان می‌دهد. هر IP یک ردیف سه‌دکمه‌ای دارد: مقدار IP، ✏️ برای تغییر و 🗑 برای حذف با تأیید. با زدن روی خود IP، رکوردهای آن را می‌بینید.
- همهٔ رکوردها یکسان‌اند. کلون صرفاً عملیات ساخت کپی روی IP جدید است و بخش مدیریتی مستقلی ندارد.
- پایین گروه فقط **کنترل اعضا، کلون جدید، تازه‌سازی و برگشت** وجود دارد.
- در **کنترل اعضا**، نام اعضا به صورت دکمه نمایش داده می‌شود. زدن روی نام، قبل از برداشتن عضو سؤال می‌پرسد. ارتباط آن عضو با همهٔ IPهای همین گروه برداشته می‌شود؛ DNS از Cloudflare حذف نمی‌شود. افزودن عضو نیز در همین صفحه است.
- حذف IP با 🗑، رکوردهای همان ردیف را از Cloudflare حذف می‌کند و سایر IPها را تغییر نمی‌دهد. پیش‌نمایش تعداد و نام رکوردها قبل از تأیید نمایش داده می‌شود.
- IP و مقدار فعلی از Cloudflare خوانده می‌شود؛ درخواست نامعتبر، تغییر دسترسی یا تغییر هم‌زمان رکورد باعث توقف عملیات قدیمی می‌شود.
- تغییر نام و حذف خود گروه با آیکون‌های کنار نام گروه در **فهرست گروه‌ها** انجام می‌شود. حذف گروه، هیچ DNSی را حذف نمی‌کند.
- تلگرام برای کیبورد معمولی ربات گزینه‌ای جهت تعیین درصد عرض هر دکمه ندارد؛ چیدمان سه‌دکمه‌ای است و عرض نهایی را نرم‌افزار تلگرام تعیین می‌کند.
- `/cancel` یا `/start` ورودی و تأیید معلق را پاک می‌کند.

### به‌روزرسانی

1. همهٔ فایل‌های سورس را در ریشهٔ مخزن قرار دهید؛ فایل‌های `bot_runtime.py` و `group_records.py` نیز لازم‌اند. تنظیمات خصوصی، اطلاعات کاربران و دیتابیس را در GitHub بارگذاری نکنید.
2. دستور نصب یک‌دستوری بالای README را اجرا کنید و گزینهٔ **3 — Update from GitHub** را بزنید.
3. تنظیمات، اعضا و ارتباط رکوردهای قبلی از پشتیبان حفظ می‌شوند. پس از به‌روزرسانی در تلگرام `/start` بفرستید.

دریافت سورس پیش از توقف سرویس انجام می‌شود. در نصب مجدد، نسخهٔ قبلی تا پایان نصب جدید حفظ می‌شود. در خطای نصب/به‌روزرسانی، بازگردانی نسخهٔ قبلی تلاش می‌شود؛ خطاهای سیستم یا شبکه ممکن است نیازمند بررسی لاگ باشند.

### آزمون آفلاین

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
bash -n setup.sh install.sh
```

آزمون‌ها شبیه‌سازی‌شده‌اند و به توکن واقعی نیاز ندارند. نصب یا آزمون زنده روی حساب کاربر انجام نشده است. عملیات چندرکوردی Cloudflare تراکنش یکپارچه نیست؛ در خطای بخشی از عملیات، تغییرات موفق حفظ و موارد ناموفق جداگانه گزارش می‌شوند.
